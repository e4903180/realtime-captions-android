# Second pass: correcting finished lines with a whole-sentence model

**Result (2026-11-28):** not adopted. Every model made the overall CER worse; `SecondPass.choose` replaced almost every line (630 of 634), so second-pass errors overwrote the live text. Only SenseVoice 2024 helped slightly on the NTU lectures (14.0% → 13.3%).

**Config.** ASR x-asr-160ms-int8, 4 threads, 20 ms audio chunks, VAD threshold 0.65, line end after 0.6 s of silence, ASR endpoint 0.8 s, line joining < 1.5 s, speaker model campplus-zh-en @ 0.5 (new speaker from ≥ 1.0 s), focus filter off, denoiser off. Line end, line joining, chunk size and threads are the Android app's.

Generated by `:desktop --second-pass` on 2026-11-28 (Windows 11, 20 logical CPUs). Live captions use X-ASR 160 ms with line end after 0.6 s silence (config above). After each line ends, the whole-sentence model hears that line's audio again and its text replaces the live text (unless it is much shorter or longer; see `SecondPass.choose`). See ADR-025.
