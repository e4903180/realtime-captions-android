**發現：**
- **朗讀語料（cvtw）：** 模型單獨辨識比即時 X-ASR 好 1～2 個百分點，但進了 App 流程卻變成 17～20%。實際抽查發現，交給第二遍的音段常常少了開頭幾個字，例如即時「很少一百二十…」、第二遍只有「一百二十…」。原因是 ASR 斷句和 VAD 音段沒有對齊。把 pre-roll 從 0.3 秒加到 1.0 秒只改善一點（2 個檔：20.1% → 18.6%）。
- **YouTube（yttw）：** 模型本身就比 X-ASR 差 3～6 個百分點。
- **ml2021：** 講課檔整個是一段好幾分鐘，這些模型不能一次處理，數字不算數。
- **SenseVoice：** 開了 ITN 會把數字寫成阿拉伯數字（「6 年前」），數字統一後在 cvtw 少 1.5 個百分點。

**結論：** 流程切段確實有問題，但就算修好，模型本身的上限也不夠：朗讀只好一點，真實影片反而更差，不值得每句多花時間。維持不採用，切段也不修。
