# 路線圖

最後更新：2026-11-27

## 已完成

- 專案骨架：`:core`（引擎介面、字幕組裝、文字處理）與 `:app`（Compose 字幕畫面）
- 手機內建語音辨識引擎（連線／離線），自動連續聆聽
- 字幕畫面：大字、高對比、已確定／未確定字分色、說話者標籤與顏色、字體大小調整、螢幕常亮
- 摺疊螢幕支援、前台服務（避免 ColorOS 在背景停止收音）
- 麥克風音量條與「沒有聽到聲音」提示
- GitHub Actions：核心測試＋編譯 debug APK
