Generated by `:desktop` on 2026-11-27 (Windows 11, 20 logical CPUs, simulated real-time clock). Same metrics as [benchmark.md](benchmark.md). Regenerate with:

```
bash testdata/real/download_real.sh datasets      # ~3.6 GB
python testdata/real/prepare_real.py datasets
./gradlew :desktop:run --args="--models <model dir> --real datasets/prepared"
```
