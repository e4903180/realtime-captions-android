# 產品需求

最後更新：2026-11-27

## 目的

即時把說話內容轉成字幕，讓聽障朋友能跟上日常對話。先給自己和家人使用，之後當作作品集。

## 使用情境

- 日常生活：吃飯、聊天、看電視、外出
- 環境常常**很吵**，而且**多人同時在場、輪流或同時說話**
- 需要**分辨不同的說話者**

## 優先順序

1. **速度第一：** 字要在說話的當下逐字出現，不等整句講完
2. **品質緊接在後：** 在吵雜環境也要可讀；不能憑空冒出假字幕
3. 易讀：大字、高對比、清楚區分「已確定」和「可能還會變」的字

## 語言

- 主要：國語（**台灣口音**，輸出**台灣繁體與台灣用語**）
- 次要：英語、台語
- 未來：多語即時翻譯
- 口音和語言的處理在背景完成，使用者不需要選擇

## 平台

- 先做 Android 手機；目標機型 OPPO Find N6（摺疊機、ColorOS），也要完整支援一般手機（Android 8.0 以上）
- 未來可能移植到智慧眼鏡等裝置，所以辨識和文字處理放在與畫面無關的核心模組

## 連線與離線

- 兩種都要：離線（手機上的模型）和連線（雲端或自架辨識伺服器）
- 可以租用雲端 GPU 伺服器，用來支援台語和更高品質的辨識

## 驗證要求

- 噪音處理要經過有數據的驗證（真實噪音、不同噪音強度、有無降噪、純噪音不冒假字幕）
- 口音要分開評估，以台灣口音的結果為主要依據
