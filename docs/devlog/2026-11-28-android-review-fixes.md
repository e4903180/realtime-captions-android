# 2026-11-28 Android 檢視後的修正

tony：「重新審視整個程式碼及計劃，找出能加強的部分」「把能做的部分全部完成」。這一批是讀程式碼就能確認的問題。

- 逐字稿存檔：存檔原本跟著畫面的生命週期，App 被關掉時最後一次存檔會被取消（最多少掉最後 3 行或 20 秒）。改成獨立的寫檔工作，畫面結束時也會先結束工作階段、存好用量和逐字稿，並收掉「正在收音」的通知。
- 畫面更新：音量事件每秒 50 次，原本每一次都會比對整份逐字稿並更新整個畫面。現在音量條每秒最多更新約 15 次，逐字稿只在一句話完成時才比對。
- Azure 斷線：原本只有金鑰錯誤和連線逾時會顯示訊息，其他錯誤字幕會默默停住。現在所有錯誤都會顯示原因。
- 字體大小會記住，下次開 App 不用重調。
