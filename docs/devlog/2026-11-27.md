# 開發日誌 2026-11-27

## 規劃

- 確認需求：給聽障朋友看的即時字幕；國語為主（台灣口音），英語、台語次之；日常吵雜、多人說話、要分辨說話者；速度第一、品質兼顧；連線和離線都要；先做 Android。詳見 [requirements.md](../requirements.md)。
- 研究現有產品與開源專案：Google 即時轉錄、Ava（介面參考）；sherpa-onnx（離線引擎）；Taiwan Tongues ASR、BreezeASR-Taigi（台語，需伺服器）；faster-whisper（伺服器端）。

## 第 1 步：專案骨架

- 建立 `:core` 與 `:app`，見 ADR-001～004。
- 開發環境的雲端容器無法下載 Android SDK，所以用 GitHub Actions 編譯 APK，核心模組在容器內用 JVM 測試。
- PR #1：摺疊螢幕不重建畫面、麥克風前台服務（針對 OPPO Find N6 / ColorOS）。
- 使用者決定需要分辨說話者 → ADR-005。

## 測試環境

- 原本打算用 MacBook Air，但磁碟只剩 34 GB，改用 Windows 桌機（i7-12700KF、32 GB、RTX 4070）。
- 安裝 Android Studio、SDK、JDK 17（專案的 Gradle 8.11 不支援 Studio 內建的 JDK 25）、Pixel 8 與 Pixel Fold 模擬器。
- **問題：** 第二次重新開機打斷了測試。原因是先前排定的「60 秒後重開機」還沒執行就繼續工作。**教訓：** 不自行排程重開機，開始長時間工作前先確認沒有待執行的重開機。
- **問題：** App 在模擬器上一直沒有字幕，麥克風圖示一直閃。紀錄顯示 Google 辨識每 5 秒回報「沒有偵測到語音」後重新開始；Windows 的麥克風使用紀錄裡沒有模擬器，代表模擬器沒有拿到電腦麥克風。換音訊後端、冷開機都無效。**解法：** 改用 AirPods 當 Windows 預設錄音裝置後，模擬器收得到聲音，連線辨識正常出字幕。
- PR #2：加上麥克風音量條、連續沒聽到聲音時的提示，以及辨識事件的紀錄，方便之後診斷同類問題。
- 模擬器沒有台灣中文離線語音包，系統內建的離線模式在模擬器上無法測試。
- 沒有實體 Android 手機 → ADR-008。

## 第 2 步：離線引擎（進行中）

- 測試資料：
  - 用 Windows 台灣中文語音（Yating、Hanhan、Zhiwei）合成 6 段多人對話（中文、中英夾雜、英文），附逐字稿與說話者分段，並混入噪音
  - 真實語音：Common Voice zh-TW（只留台灣錄音者）、台大機器學習課程錄音、創用 CC 影片配人工字幕；中國口音對照組 AISHELL-1、AliMeeting
  - 測資放在 `datasets/`（不上傳 GitHub），只提交下載與處理腳本
- 引擎：X-ASR 串流模型（160 ms、int8）＋ Silero VAD（門檻 0.65）＋ 3D-Speaker CAM++ 線上分群；合成語音初步結果錯字率約 1.5%、說話者約 98% 正確、約 0.8 秒出字。
- 使用者要求：口音要分開評估（ADR-009）、噪音要經過數據驗證（真實噪音、SNR 20 到 -5 dB、三種降噪設定比較、純噪音假字幕測試）。
- PR 改為 CI 通過即自動合併（ADR-010）。
