# 2026-11-28 Android AI 校稿

和 iPhone 相同的做法（ADR-026），共用核心的提示詞、輸出格式與「改太多就不採用」的檢查。

- 「雲端服務設定」新增「AI 校稿（Claude）」：填自己的 Anthropic 金鑰、測試金鑰、開關、選模型（Opus 5.5／Haiku 5.5）。預設關閉。
- 每句說完約 2 秒後送出（同一個人可能還在接話），一次最多 6 行，附前 4 行當上下文。只送文字。
- 修正結果直接更新字幕和逐字稿；送出後這一行又變長的話，這次的修正不套用，下一輪再校。
- 暫時性錯誤（逾時、網路、忙碌）自動重試，間隔 5 秒起逐次加倍到 60 秒，連續兩次失敗才顯示黃字；金鑰錯誤或額度不足則暫停到換金鑰為止。
- 用量：依回傳的 token 數估算本月費用，顯示在卡片上；目前不計入每月雲端費用上限。
- Android 用官方 Anthropic Java SDK（`com.anthropic:anthropic-java`）。

尚未用真的金鑰在 Android 上跑過；需要 tony 填金鑰後實測。
