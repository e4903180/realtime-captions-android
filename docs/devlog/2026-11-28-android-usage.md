# 2026-11-28 Android 雲端用量畫面

- tony 要求「要有畫面去算跟統計雲端 API 的用量」。iPhone 版已做（ADR-028），Android 照同樣方式補上。
- 位置：雲端服務設定 →「雲端用量與費用」。
- 記錄方式：使用 Azure 時每 10 秒、以及停止時，把使用秒數記到當天（SharedPreferences，只存在手機，保留約一年）。
- 顯示：今天／本月／全部的使用時間與估計費用；單價可改（預設每小時 1 美元）；免費方案（F0）每月 5 小時的進度條，用到 80% 變橘色；可以歸零（會先確認）。
- 計算邏輯放在共用核心 `core/CloudUsage.kt`（含單元測試 `CloudUsageTest`），免費額度按月計算。
- 限制：只算這支手機，是估計值；實際帳單看 Azure 入口網站「成本管理」。Android 版沒有 AI 校對，所以不記 token。
