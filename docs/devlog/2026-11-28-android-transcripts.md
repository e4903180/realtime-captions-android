# 2026-11-28 Android 逐字稿紀錄

- tony：「要做記憶功能 記住之前的逐字稿可以回去看 並且要可以下載」、「把兩邊功能做對齊」。照 iPhone 版 ADR-029 做。
- 每次按「開始」到「停止」自動存成一份（字幕畫面下方「紀錄」）。收音中每 3 句或 20 秒存一次；停止後替人命名等修改也會更新進去，直到下次按開始。按「清除」只清畫面，不刪紀錄。
- 紀錄畫面：新的在上、搜尋標題與內容（命中的字標黃色）、改標題、刪除、全部刪除、可以關掉自動保存。
- 匯出：「下載 .txt」（[時:分:秒] 說話者：文字）、「下載 .srt」字幕檔（每句顯示到最後一個字後 1 秒、至少 1.5 秒，不蓋到下一句），用系統的「儲存到」選位置；也可以分享或複製全文。
- 格式與計算放在共用核心 `core/Transcript.kt`（含 `TranscriptTest`），iPhone 版之後也可以沿用。
- 隱私：只存在 App 的私有資料夾（filesDir/transcripts，每份一個 JSON），不上傳、不存聲音。
- 控制列按鈕變多，這一列改成可以左右滑動。
