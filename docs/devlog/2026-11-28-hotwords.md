# 2026-11-28 離線自訂詞彙（ADR-038）

- 做了一組人名地名測資：20 句台灣人名、地名、店名的句子，3 種 TTS 聲音（`testdata/hotwords/names.json`、`generate_names.ps1`），和 `:desktop --hotwords-test`。
- 第一輪：照打、轉簡體、換 cjkchar+bpe、調分數，都只多認對 3 個詞。用 sentencepiece 查 X-ASR 的 bpe.model，發現「林怡君」被編成「▁林」＋unknown，繁體「鶯歌」整個是 unknown。
- 第二輪：轉簡體＋每個字加空格（「林 怡 君」），分數 4.0：詞彙認對 43% → 74%，錯字率 13.5% → 8.2%，沒有亂插詞。
- 接上 Android 離線引擎後，模擬器上沒效果。逐步排查：
  - 設定確實傳進辨識器（modified_beam_search、hotwords_file、bpe）。
  - Android 的結果和電腦上「beam search 不加詞彙」一模一樣。
  - 把手機產生的檔案拿到電腦上跑，也沒效果。
  - 原因：手機上自己產生的 bpe.vocab 分數全是 0，「▁」和「▁林」平手。
  - 改成照 bpe.model 的順序給分數後，電腦和模擬器都正確（林怡君、頭份、黃柏翰）。
- 已經用舊版產生過 vocab 的手機：檔名改成 `asr-bpe-v2.vocab`，會重新產生。
- debug 版新增 `--es vocabulary "詞1,詞2"`，可以在模擬器上設定詞彙測試。
