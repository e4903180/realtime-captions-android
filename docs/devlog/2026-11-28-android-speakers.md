# 2026-11-28 Android 接行、說話者重新分組、說話人數、說話者辨識開關

tony：「把兩邊功能做對齊」。照 iPhone 版的共用核心做法（ADR-024、ADR-027、ADR-033），不另外重寫。

- 接行（ADR-024）：離線引擎改成靜音 0.6 秒才結束一句（原本 0.4 秒）；同一個人 1.5 秒內接著說的話接在同一行，句子不再被切碎。灰色的即時字一樣馬上出現。
- 事後重新分組（ADR-027）：每完成一句，就用全部句子的聲音重新分組，前面標錯的說話者也會被改正。有名字的人與背景聲音維持原本的標籤。門檻 0.45，和 iPhone 相同。
- 說話人數：「選擇辨識引擎」的「說話者」裡可以選 自動／2～6 人；選了人數，分人會比較準。改人數時，畫面上的句子會馬上重新分組。
- 說話者辨識開關（ADR-033）：關掉後不載入分人模型、不顯示 A／B 標籤，只照停頓換行，比較省電；Azure 也不顯示說話者。
