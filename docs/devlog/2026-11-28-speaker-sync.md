# 2026-11-28 分人：即時分群與重新分組同步

檢視時發現的三個問題（共用核心，兩個平台都受益；iPhone 需在 App 端呼叫 `replaceProfiles` 才會啟用第一項）：

- 即時分群（`SpeakerClusterer`）和每句結束後的重新分組（`SpeakerRecluster`，ADR-027）是兩套狀態。重新分組改了字母，但下一句仍和舊的群比較，於是先標成舊字母、馬上又被改掉，看起來像「A 變成 D」。現在重新分組後，用畫面上每個字母的平均聲紋重建即時分群（`CaptionAssembler.speakerProfiles()` → `SpeakerClusterer.replaceProfiles()`）。Android 停止再開始時也沿用同一組，字母不會重新從 A 排。
- 同一個人接在同一行時，聲紋原本直接換成最新那句，長句的聲紋會被短句蓋掉。改成依文字長度加權平均。
- 說話滿 1 秒時，同一段聲音原本計算兩次聲紋（暫定說話者、認得的人各一次），改成只算一次。

還沒有用真實多人錄音量過改善幅度；需要在 Windows 電腦上用測試工具跑。
