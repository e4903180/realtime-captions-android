# 即時字幕 Android 版：安裝說明

## 安裝

1. 打開收到的檔案「即時字幕-版本號.apk」（從 LINE 或 Google 雲端硬碟下載）。
2. 手機會問「要允許這個來源安裝應用程式嗎？」：按「設定」，打開「允許這個來源」，再按返回。
3. 按「安裝」。
4. 如果出現「Play 安全防護」的提醒，按「更多詳細資料」→「仍要安裝」。這是因為這個 App 不是從 Play 商店下載的。

## 第一次使用

1. 打開「即時字幕」，按「開始」。
2. 允許「錄音」權限，字幕才聽得到聲音；允許「通知」，螢幕關掉時也能繼續聽。
3. 第一次會下載離線辨識模型，大約 160 MB，請先連上 Wi-Fi。下載完就不需要網路，也不花錢。
4. 把手機放在說話的人附近，字幕就會出現。不同的人會標示 A、B、C。

## 常用功能

- **A− ／ A+：** 字變小／變大。
- **看電視：** 字更大、置中，適合看電視時用。往上滑可以看前面的句子，按「↓ 回到最新」回到最新一行。
- **長按一句字幕：** 告訴 App 這句是誰說的（例如「媽媽」），之後會自動顯示名字。
- **紀錄：** 每次的字幕都會存在手機上，可以再看或分享。
- **雲端設定：** 想用更準的雲端辨識（Azure）時，要填自己的金鑰，會照使用時間計費。不填也可以，App 會用免費的離線辨識。

## 更新

收到新版的 APK 時，直接打開安裝，選「更新」即可。字幕紀錄、認得的人和設定都會保留，模型不用重新下載。

## 隱私

- 離線辨識：聲音只在手機上處理，不會上傳。
- 字幕紀錄和聲音特徵只存在這支手機上。
- 只有你自己在「雲端設定」打開雲端辨識或 AI 校稿時，聲音（Azure）或字幕文字（AI 校稿）才會送到那個服務。

## 有問題時

- **按了開始沒有字：** 確認有允許錄音權限（設定 → 應用程式 → 即時字幕 → 權限 → 麥克風 → 允許）。
- **出現「麥克風被其他 App 使用中」：** 先結束通話或關掉其他錄音的 App。
